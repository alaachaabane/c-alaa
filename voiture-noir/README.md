# REAL DRIVE — La route des Crêtes

Prototype de conduite arcade en 3D WebGL, dans un seul fichier HTML et sans dépendance externe. Il comprend une route côtière sinueuse, un relief stylisé, des voitures en volumes 3D, du trafic, trois caméras, trois ambiances lumineuses, la pluie, une mini-carte, des collisions et un son moteur synthétisé.

## Lancer le jeu

Ouvrir `index.html` dans un navigateur récent avec WebGL activé. Le jeu ne nécessite ni installation ni connexion réseau.

## Commandes

- **W / ↑** : accélérer
- **S / ↓** : freiner
- **A D / ← →** : diriger
- **Espace** : frein à main
- **C** : changer de caméra
- **N** : changer l’ambiance lumineuse
- **M** : activer ou désactiver la pluie
- **R** : revenir sur la route
- **Échap** : pause

Le rendu est une interprétation low-poly légère, optimisée pour fonctionner directement depuis le fichier. WebGL doit être disponible dans le navigateur.
